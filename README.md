# 📝 TO-DO LIST APPLICATION

A simple To-Do List web application built using **Node.js**, **Express.js**, **MongoDB**, and **EJS**.

---

# 🚀 FEATURES

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Store data in MongoDB
- Simple and responsive interface

---

# 🛠️ TECHNOLOGIES USED

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- CSS
